1. 
The Python requests module is a third-party library that makes HTTP requests from Python applications
much simpler. It provides an interface for sending requests to servers without requiring the networking
back-end. The requests module can be used to establish communication between web services and APIs, forms,
files, content, etc. Requests is used by functions like requests.get() or requests.post(). The server 
responds to these requests with an object with information about the content and HTTP status. 

2.
JSON (JavaScript Object Notation) and XML (eXtensible Markup Language) are data formats used to store and
exchange information between applications and systems. 

JSON uses key-value pairs and arrays. XML uses tag-based structure.

Advantages of JSON are (1) simple syntax, (2) smaller file size, (3) faster parsing, and (4) compatilibility
with JavaScript. Some disadvantages are (1) no commenting, (2) less validation features, (3) difficulty to read,
and (4) less support for more complex things.

Advantages of XML are (1) commenting, (2) schema validation, (3) descriptive tags, and (4) representation for
more complex data. Disadvantages are (1) larger file sizes, (2) slower parsing, (3) more difficult syntax, and
(4) generally more complex than JSON.

3.
A RESTful API (Representational State Transfer Application Programming Interface) is a web service that provides
functionality to software applications to communicate with each other. It uses HTTP to communicate among applications.

Advantages of RESTful APIs are (1) simplicity, (2) scalability, (3) independence per application, and (4) support for
multiple data formats like both JSON and XML. Disadvantages include (1) lack of security, (2) need for extra authentication
implementation, (3) performance issues during heavy traffic times, and (4) limited support for real-time communication.
