bash-3.2$ curl -X POST https://postman-echo.com/post -d "key=value" -H "Content-Type: application/x-www-form-urlencoded"


*******************************************************************


1. GET retrieves data, POST sends data
2. The payload (key=value) contains the data being sent. It is transmitted in the HTTP request body (“content-type”:”application/x-www-form-urlencoded”).
3. The response body is JSON data of what the server received. The server responds with data in the “form”:{“key”:”value”} field
